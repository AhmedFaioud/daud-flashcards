# Recording script — Volume 0 sound library

Built from the book's own answer keys: for every dictation track the items below are the exact
ten the answer key states. Drill tracks take their items from the page that cites them.

**Protocol:** 300 ms of silence at both ends · 2-second gaps · MP3 128 kbps mono · peak −3 dB.
**Naming:** `A1.1-C04-T02.mp3` = Volume 0, chapter 4, track 2.

**44 files.**
